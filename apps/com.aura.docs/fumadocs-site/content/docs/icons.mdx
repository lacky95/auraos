**TL;DR.** AuraOS uses [Lucide](https://lucide.dev/icons) (~2000 line
icons) as its default icon set. The shell chrome draws with it, and the
shell serves it to every app, so you don't need to install anything. Icons stroke
`currentColor`, so they follow the active [theme](/docs/core-concepts#theme-system)
on their own.

## Recommended, not required

The recommended setup for an app is the OS theme (`themeStrategy:
'inherit'`) plus the OS icons. Your app then looks and recolors like the
rest of the desktop, and you ship no icon library of your own.

It is a recommendation, not a rule. Any app can bring its own stack:
another icon library, its own SVGs, an icon font. That pairs naturally
with `themeStrategy: 'themed'` or `'override'` (see
[Theme pipeline](/docs/deep-dive/theme-pipeline#three-themestrategy-modes)),
but nothing stops you from mixing your own icons with the OS palette either.

## Three ways to use the OS icons

Names are always Lucide's kebab-case ids, e.g. `settings`, `rotate-cw`,
`mic-off`. Look them up at https://lucide.dev/icons.

### 1. The sprite — any framework, no dependencies

```html
<svg class="aura-icon"><use href="/api/os/icons.svg#lucide-settings"/></svg>
```

- `/api/os/icons.svg` is a `<symbol>` sprite of a **curated set of about
  100 icons**: everything the shell chrome uses plus the common vocabulary
  (`check`, `plus`, `trash-2`, `search`, `play`, `folder`, `user`, `bell`
  …).
- Symbol ids are `lucide-<name>`.
- `.aura-icon` ships in the injected `/api/os/theme.css`. It sizes the icon
  to `1em` and aligns it with the text around it. Set your own
  `width`/`height` to change the size.
- The stroke follows the element's CSS `color`, so
  `style="color: var(--aura-color-danger)"` gives you a red icon in every theme.
- An unknown symbol id renders nothing; it doesn't throw an error. If an icon doesn't show up, check
  that it's in the sprite: `curl "$OS_API_BASE/api/os/icons.svg"`.

Works in plain HTML, Astro and React alike. This is the default choice.

### 2. A single icon — the full Lucide catalogue

```html
<img src="/api/os/icons/git-branch.svg" alt="" width="16" height="16">
```

- `/api/os/icons/<name>.svg` serves **any** Lucide icon as a standalone
  SVG. Unknown names return `404`.
- Use it for icons that aren't in the curated sprite, as an `<img src>`, a CSS
  `mask-image`, or fetched and inlined.
- Caveat: a standalone SVG document can't see the page's `color`, so an
  `<img>` won't follow the theme. To get theme colors, use the sprite, inline the
  markup, or use it as a CSS mask over `background: currentColor`:

```css
.icon-branch {
  width: 1em; height: 1em;
  background: currentColor;
  mask: url(/api/os/icons/git-branch.svg) center / contain no-repeat;
}
```

### 3. React with `@aura/ui`

```tsx
import { Icon } from '@aura/ui';

<Icon name="rotate-cw" />
<Icon name="alert-triangle" size={20} className="text-[var(--aura-color-warning)]" />
```

- Takes the kebab-case Lucide name (PascalCase works too), defaults to
  `1em`, uses `currentColor` and sets `aria-hidden`.
- An unknown name renders nothing and logs a console warning; it
  doesn't crash the tree.
- `<Icon>` looks icons up by name, so it bundles the whole Lucide map. If
  bundle size matters, import from `lucide-react` directly
  (`import { RotateCw } from 'lucide-react'`). You still get the same set and
  the same look.

## Which one to pick

| Situation | Use |
|---|---|
| Plain HTML / Astro, common icon | Sprite (`/api/os/icons.svg#lucide-…`) |
| Icon not in the curated sprite | `/api/os/icons/<name>.svg` (inline it or use it as a mask to keep theme colors) |
| React app on `@aura/ui` | `<Icon name="…" />` |
| React app, bundle size matters | `lucide-react` direct imports |
| Your own design language | Your own stack, with `themed` / `override` |

## The launcher icon is separate

The `icon` field in `app.manifest.json` (and `aura dev new --icon`) is
still a **1–3 character text glyph** (`H`, `HL`, `HEL`). The launcher, dock
and Process Manager show it as text, and it falls back to the first letter
of the app name. It is not a Lucide name. See
[Develop an App](/docs/develop-an-app).

## Under the hood

```
lucide (npm)  ──▶  IconManager            packages/core/src/theme/IconManager.ts
                    ├─ renderSprite()  ──▶ GET /api/os/icons.svg        (curated, ETag + no-cache)
                    ├─ renderIconSvg() ──▶ GET /api/os/icons/<name>.svg (any icon, cached 1 day)
                    └─ renderIconSvg() ──▶ shell chrome (Icon.astro, rendered at SSR time)

lucide-react  ──▶  <Icon>                 packages/ui/src/components/ui/icon/icon.tsx

.aura-icon CSS ─▶  ThemeManager.toCss()   → part of /api/os/theme.css
```

- **Growing the sprite:** add names to `CURATED_ICONS` in `IconManager.ts`.
  Each icon adds about 150 bytes. The sprite's ETag is a content hash, so
  browsers pick up the new sprite on their next load.
- **Endpoints:** `packages/shell/src/pages/api/os/icons.svg.ts` and
  `packages/shell/src/pages/api/os/icons/[name].svg.ts`.
